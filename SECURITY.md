# Security policy

chaat-push-relay is an early draft. Security fixes target `main`.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/gkachru/chaat-push-relay/security/advisories/new).
Keep suspected vulnerabilities out of public issues and pull requests.

Include the commit, operating system, cloudflared version, steps to
reproduce, and the impact. Use synthetic data. Do not include tokens,
tunnel credentials, private keys, real notification bodies, or screenshots
containing account data.

For a normal bug without a security impact, open a GitHub issue. The
README's Privacy section explains what the plugin sees and sends.
